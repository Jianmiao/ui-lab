# AI Relay Station — Login

## Concept

A login screen for an AI routing console. The emotional target is calm, clear and lightly futuristic: a quiet control surface rather than a game HUD.

## Layout

- 16:9 desktop composition, 55/45 split between the visual field and the login panel.
- Left side: abstract model-routing mesh, signal arcs and node points; no characters, maps or brand marks.
- Right side: a single frosted login card with a clipped top-right corner.
- Top bar: product mark, product name, service status and time.
- The login card contains two tabs, two fields, one primary action and one secondary API-key entry.

## Color and material

| Token | Value | Use |
|---|---|---|
| canvas | `#F7FAFC` | page background |
| surface | `#FFFFFF` | card and inputs |
| ink | `#1B2A36` | titles and body |
| muted | `#5E7180` | supporting copy |
| accent | `#35C8DA` | primary action, focus, active nodes |
| line | `#C9D8E2` | 1px strokes |

Recommended ratio: 70% cool white / mist blue, 20% neutral structure, 10% accent. The ratio is a design constraint for this study, not a measurement from any existing product.

## Components

- Login card: 24px radius, 1px stroke, low-contrast shadow, optional single clipped corner.
- Inputs: 48px height, 12px radius, visible label, focus ring in accent color.
- Primary button: 48px height, accent fill, one clear action label.
- Secondary button: transparent fill with 1px accent-tinted stroke.
- Tabs: text tabs with a 2px accent underline for the active state.

## Copy

- Product: `AI 中转站` / `AI RELAY STATION`
- Headline: `连接每一次智能调用`
- Subline: `统一接入 · 密钥管理 · 用量追踪`
- Login title: `登录中转站`
- Tabs: `账号登录` / `API Key`
- Fields: `邮箱 / 用户名` / `密码`
- Primary action: `进入中转站`
- Secondary action: `使用 API Key 登录`

## Originality boundary

This study uses no original game screenshots, logos, character art, icon sets, font files or layout code. The node mesh, product mark, component geometry and copy are original. It is not a reproduction of any specific game interface.
