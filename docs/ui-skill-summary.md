# UI Skill Summary

## Evidence levels

- `[F]` Publicly supported high-level traits.
- `[R]` Design recommendations created for original work.
- `[X]` Specific expression or assets that must not be copied.

## Five dimensions

### 1. Design DNA

Airy, orderly, lightly futuristic, touch-first. The interface should feel like a calm tablet control surface: generous whitespace, clear hierarchy and restrained material effects.

### 2. Color

Use a cool white / mist blue base, a neutral ink layer and one cyan-blue accent. Recommended ratio: 70% light space, 20% structure, 10% accent. Keep body text at 4.5:1 contrast or better.

### 3. Type and grid

Use a geometric or humanist sans-serif with an open-source Chinese sans companion. Base spacing on 8px. Desktop: 12 columns; tablet: 8; mobile: 4. Keep one primary action per view and no more than three hierarchy levels.

### 4. Shape and material

Prefer rounded rectangles, 1px strokes and soft low-contrast shadows. Use light translucency sparingly. A single clipped corner is an optional original device, not a required imitation.

### 5. Components

Touch targets are at least 44×44px. Primary buttons use a solid accent fill; secondary buttons use a 1px stroke. Cards use 16–20px radii and 20–24px padding. Modals use a 40% scrim and at most two actions.

## Boundary

Do not copy specific screens, logos, characters, school crests, weapon silhouettes, icon sets, font files or layout code. Do not trace or overlay reference screenshots. Change at least three structural choices: navigation, grid, card composition, component geometry or motion.
