## Featured: AI Relay Station — Login

A clean academy-tech inspired login screen for an AI relay station. The design is an original study: it borrows only high-level qualities such as airy spacing, a cool white/blue palette, tablet-like touch rhythm and a restrained flat-2.0 material language.

![AI Relay Station login](assets/ai-relay-login.png)

### Design notes

- 70% cool white / mist blue breathing space, 20% neutral structure, 10% cyan accent.
- Touch-first: 44px targets, clear focus states, one primary action.
- Flat surfaces with light translucency, 1px strokes and soft low-contrast shadows.
- Abstract node and route visual instead of character art or brand marks.
- No affiliation with any game or brand; no original game assets are used.
